# claudecode-agents

This repository has moved to [rzem-ai/coder-fleet](https://github.com/rzem-ai/coder-fleet). The plugin is now called `coder-fleet`, and what lived here is under `claude/` in the new repository: the plugin at `claude/coder-fleet/`, with its evals, home files and scripts beside it.

To move an existing install, run `claude/scripts/install-home.sh` from a checkout of the new repository, then `claude plugin install coder-fleet@rzem`. The marketplace name, `rzem`, is unchanged, and its `renames` map moves the `enabledPlugins` key for you.

This repository is archived and read-only. Its history stays here.
